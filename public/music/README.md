# Music (optional)

Drop an audio file here and point `NEXT_PUBLIC_MUSIC_URL` at it, e.g.

```
NEXT_PUBLIC_MUSIC_URL=/music/our-song.mp3
```

The control in the top-right corner stays **off** until the visitor presses it,
remembers the choice in `localStorage`, and handles blocked autoplay quietly.
With no file configured the button still works — it simply governs the little
celebration chimes instead.

Use a track you have the right to host (an instrumental you both like, kept
small — 2–4 MB is plenty for a phone).
